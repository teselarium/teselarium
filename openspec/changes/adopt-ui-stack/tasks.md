# Tasks

Each group that changes behavior writes or updates its tests first and names each test after the spec scenario it covers, so every scenario in `specs/theme`, `specs/mod-theme` and `specs/default-mods` can be traced to a test. Unit tests run in Node (Vitest project `lib`), component tests in jsdom (project `app`), and page and frame styles in Playwright on the built app.
