# Specifications
## Description

OpenTesela is an application for creating, sharing and viewing knowledge files (markdowns) via interactive UI plugins. It has as goal to promote the collective creation of knowledge and its visualisation. It is implemented as a Single Page Application design to be self hosted via static files like github pages. Knowledge files are markdown files with frontmatter following principles of structural typing.
