# Rules for Claude

- Never create git commits, push, or change git history. The user commits.
- Never create GitHub issues, pull requests, comments or reviews.
- Never post anything to an external service (issues, comments, forms, chats).
  When something should be reported, write a draft and give it to the user.
- Before writing code, read `docs/code_principles.md`, then read `docs/code_conventions.md`. Read each once per session, and again only when its text is no longer in your context.
