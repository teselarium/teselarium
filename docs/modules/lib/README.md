# Lib Modules

The `lib` modules hold the app's logic, and render nothing:

- [files](files/README.md): fetching and parsing files, picked files and files stored in the browser.
- [tile](tile/README.md): tiles and tile collections.
- [mod](mod/README.md): mod files.
- [mosaic](mosaic/README.md): mosaic files.
- [user catalog](user_catalog/README.md): the user's own mosaics, their provenance and the import review.
- `core`: the engine and what it runs on:
  - [engine](core/engine/README.md), [stage](core/stage/README.md), [sandbox](core/sandbox/README.md), [permissions](core/permissions/README.md), [storage](core/storage/README.md), [theme](core/theme/README.md), [players](core/players/README.md), [tile bodies](core/tile_bodies/README.md) and [combinations](core/combinations/README.md).
