# Page Layout

The page layout consist in:
- A header with the name of the app "OpenTesela", the logo (not yet defined)
- A sidebar on the left with the sections:
  - Home
  - Tiles
  - Mods
  - Mosaics
  - Settings
  - About
- A body that also contains the sandbox where the mods will be loaded
- A status bar
- A footer

The left sidebar is collapsible to a hamburger menu.
