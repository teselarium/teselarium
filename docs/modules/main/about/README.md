# About

The About section is a page section, always shown at the bottom of the sidebar. Its index page is `pages/about/index.md`, at `#/about`. An instantiation replaces that file to describe itself, and may add sibling pages (`pages/about/<page>.md`, at `#/about/<page>`).

About pages work like every page section: see [Pages](../homepage/README.md) for the files and addresses, the allowed HTML, links and images, and how pages share the mods' look.
