# Mosaic Maker

There is no separate mosaic maker. Making and changing mosaics is the [mosaic viewer](../viewer/README.md)'s edit mode: "Edit" for a mosaic stored in this browser, "Edit a copy" for any other, and a new mosaic from a combination, which the stage bar's mosaic list opens with "Save as mosaic" (see [Edit mode](../viewer/README.md#edit-mode)). The app saves the drafts, through its "Save mosaic" confirmation, into the [user catalog](../../lib/user_catalog/README.md).
