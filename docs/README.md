# Specifications
## Description

OpenTesela is an application for creating, sharing and viewing "Mosaics" of knowledge "Tiles". It has as goal to promote the collective creation of knowledge and its visualization. Tiles are markdown files with frontmatter following principles of structural typing for promoting modular and de-centralized usage. Mosaic Designs (mods) are javascript plugins for displaying tiles. OpenTesela is implemented as a Single Page Application design to be self hosted via static files like github pages.
