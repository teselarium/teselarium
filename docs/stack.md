## Stack

- Typescript
- React
- React Testing Library
- Tailwind CSS (v4, through its Vite plugin; the entry is `src/main/app.css`)
- shadcn/ui (generated into the vendored zone `src/vendor/shadcn/`, see `docs/code_conventions.md`, "Vendored code")
- lucide-react
- Oxlint
- Prettier
- Vite
- Vitest
- Playwright
- react-i18next
- ajv
- @11ty/gray-matter
- react-markdown, with remark-gfm, rehype-raw and rehype-sanitize (the markdown pages, see `docs/modules/main/homepage/README.md`)
- js-yaml
