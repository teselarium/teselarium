# About OpenTesela

Modular and reusable knowledge.

OpenTesela turns plain notes into views you can share with a link. It runs as static files, with no server and no account.

## Made with AI in mind

AI assistants are widely used to parse information and embed it inside an app. However, most of this knowledge ends up being locked in the app that contains it and with only one way of viewing it:

- Sharing markdown files and visualization plugins could let that work be reused instead of repeated. This could help to a more sustainable use of the AI instead of parsing the same web pages and creating the sames apps.
- Markdown is easy for people and for AI to read, write and reformat.
- The mod API is small, so an AI can write a new mod for a new use. A mod can ship its own tests, so the result can be checked.
- The app is a static page, so it is easy to run and test anywhere.
